# `@seaglass/react`

React 18+ adapters for Sea Glass. Import `@seaglass/css` once in your app.

```tsx
import '@seaglass/css';
import { Glass, List, ListItem, Dialog, Menu, MenuItem, Divider } from '@seaglass/react';
```

Shipped: `Glass`, `List` / `ListItem`, `Divider`, `Dialog` (focus trap + Escape), `Menu` / `MenuItem`.
More controlled form controls come later — until then use the CSS class names (`sg-button`, …).

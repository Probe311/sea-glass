# Examples

Exemples CSS minimaux. Catalogue React : [`packages/react/README.md`](../packages/react/README.md) · Storybook : `pnpm storybook`.

```bash
pnpm build
python3 -m http.server 4173 --directory ..
# open http://127.0.0.1:4173/examples/
```

Needs `@sea-glass/css` - from npm (`pnpm add @sea-glass/css`) or the built `packages/css/dist` in this monorepo.

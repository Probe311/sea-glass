# Security Policy

## Supported versions

| Version       | Supported   |
| ------------- | ----------- |
| `0.x` (alpha) | Best-effort |
| `< 0.1`       | No          |

## Reporting a vulnerability

Please **do not** open a public issue.

1. Prefer [GitHub private vulnerability reporting](https://github.com/Probe311/sea-glass/security/advisories/new) (enable it in repo settings if the button is missing).
2. Or contact [@Probe311](https://github.com/Probe311) directly.

Include the package name, version, and a reproduction. You should hear back within 7 days. We will credit reporters who want to be named.

Do not include secrets in issues, PRs, or Changesets.

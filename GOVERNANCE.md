# Governance

Sea Glass is an **open, participatory** design system. Until 1.0, it is a benevolent-dictator project.

- **Author / lead:** Julien Vaissier ([@Probe311](https://github.com/Probe311)).
- **Licence:** MIT. Contributions are DCO-signed (`CONTRIBUTING.md`).
- **Decisions:** tokens, public CSS class names, and accessibility gates are discussed in issues / RFCs (`component` template). The lead merges.
- **After 1.0:** additional maintainers can be invited; this file will list them. No CLA.
- **Code owners:** `.github/CODEOWNERS` - `@Probe311` on `*`.
- **Releases:** Changesets on `main`. npm publish is intentionally off until `NPM_TOKEN` (or trusted publishing) is configured.
- **Code of Conduct:** `CODE_OF_CONDUCT.md`. The lead is the enforcement contact.
